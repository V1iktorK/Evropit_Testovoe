# Тестовое задание — ООО «Европит»
## Разработка рабочей документации по 3D-модели бункера (PSH24-000.00)

Репозиторий содержит полный комплект конструкторско-технологической документации,
разработанной по 3D-модели бункера **PSH24-000.00** (Autodesk Inventor 2026 → STEP AP214),
переданной заказчиком.

**Изделие:** бункер PSH24-000.00 — сварная конструкция габаритом ≈ 6277×1500×5600 мм,
масса изделия ≈ **6 260 кг**, 182 позиции в спецификации (из них 128 — собственные детали).

---

## Состав комплекта

| Папка | Содержание |
|---|---|
| `01_Чертежи_2D/` | Рабочие чертежи 2D: `DXF/` (CAD) и `PDF/` (печать/просмотр). Детали — по листу на каждую (3 вида + изометрия, размеры, отверстия, технические требования); сборочные единицы — виды, позиционные обозначения, таблица состава |
| `02_Контуры_резки/` | Контуры для резки **DXF 1:1** (слой `CUT` — внешний контур, `CUT_INNER` — отверстия/вырезы, `MARK` — маркировка) + `Ведомость_заготовок.xlsx` |
| `03_BOM/` | Спецификация (иерархическая), сводный BOM, сводка материалов, таблица аналогов ГОСТ — `BOM_PSH24-000.00.xlsx` + `BOM_PSH24-000.00.csv` |
| `04_Маршрутные_карты/` | Маршрутные карты на детали (`Детали/`) и сборку (`Сборка/`) + `Перечень_маршрутных_карт.xlsx` |
| `05_Модель/` | Исходная STEP-модель сборки |
| `scripts/` | Скрипты генерации документации (Python 3, OpenCascade/cadquery, ezdxf, openpyxl) |
| `data/` | Извлечённые из модели данные: геометрия, материалы, дерево сборки с количествами |
| `docs/` | Пояснительная записка, таблицы соответствий материалов и аналогов |

## Быстрые факты

- **Материалы** взяты из свойств самой модели (STEP): S235, S355/S355JR/S355J2G3, резина, ПЭ-1000, капролон (Ertalon 6SA) и адаптированы к российским маркам (ГОСТ 380-2005, ГОСТ 19281-2014, ГОСТ 5520-2014, ГОСТ 7338-90 и др.).
- **Крепёж DIN/ISO** сопоставлен с российскими аналогами: DIN 933/931 → ГОСТ 7798-70, DIN 934 → ГОСТ 5915-70, DIN 125 → ГОСТ 11371-78, DIN 127 → ГОСТ 6402-70, DIN 929 → ГОСТ 14776-79, DIN 94 → ГОСТ 397-79 и т.д. Спорные позиции помечены «уточнить / по согласованию».
- **Массы** рассчитаны по объёму геометрии × плотность. Точность подтверждена сверкой с официальным чертёжом заказчика PSH24-070.01: расчёт **25,93 кг** против **25,9 кг** на чертеже.
- **Контуры резки** извлечены из геометрии деталей точно (линии/дуги/окружности), масштаб 1:1, единицы мм. Для гнутых панелей приведены расчётные заготовки (площадь развёртки по V/t), сверенные с данными заказчика (PSH24-070.01: расчёт 1231×543 против официальных 1227×541).
- **Маршрутные карты** — по ЕСТД (ГОСТ 3.1102-82): операции заготовительные, механические/гнущие, сборочно-сварочные, покрасочные и контрольные с указанием оборудования, оснастки и норм времени (нормы — расчётные).

## Воспроизведение

```bash
pip install cadquery ezdxf openpyxl
python scripts/gen_bom.py          # BOM + спецификация
python scripts/gen_cutting.py      # контуры резки + ведомость заготовок
python scripts/gen_drawings.py     # чертежи DXF/PDF
python scripts/gen_route_cards.py  # маршрутные карты
```

Исходные данные (`data/*.json`, `05_Модель/*.stp`) включены в репозиторий —
генерация воспроизводится без повторной загрузки модели.

## Допущения

1. Наименования деталей в STEP-модели отсутствуют (выгружены только обозначения PSH24-xxx.xx) —
   наименования присвоены по конструктивному типу («Полоса 80×6», «Труба профильная…», «Панель гнутая…»).
2. Марка стали принята из свойств модели; для позиций с некорректным/пустым материалом принята Ст3сп5 (ГОСТ 380-2005) — отмечено в BOM.
3. Размеры заготовок для гнутых деталей — расчётные (с припуском на гибы 4%); окончательные — по технологической оснастке гибки.
4. Нормы времени в маршрутных картах — расчётные, уточняются по нормативам предприятия.
5. Позиции без прямого российского аналога (штифт DIN 1444, палец ISO 2341, подшипниковые узлы SKF/UCP) помечены «уточнить / по согласованию» — допускается замена на идентичные по параметрам.
