# Пояснительная записка
## Разработка рабочей документации по 3D-модели бункера PSH24-000.00

### 1. Исходные данные
- 3D-модель: сборка `PSH24-000.00` (Autodesk Inventor 2026), формат STEP AP214 (225 изделий, 2506 вхождений).
- Образец оформления чертежа заказчика: `PSH24-070.01` (PDF/DWG) — использован как эталон состава документации и глубины проработки.

### 2. Состав и объём разработанной документации
1. **2D-чертежи** — по листу на каждую изготавливаемую деталь (128 листов) и на каждую сборочную единицу (39 листов): три проекционных вида со скрытыми линиями, изометрический вид, габаритные размеры, выноски отверстий, технические требования, основная надпись по ЕСКД.
2. **Контуры для резки** — DXF 1:1 для плоских листовых деталей (точные контуры, включая отверстия и скругления), расчётные заготовки для гнутых панелей; ведомость заготовок по всем деталям (лист, труба, пруток).
3. **BOM (спецификация)** — иерархическая спецификация по составу сборки с количествами, сводный плоский BOM, сводка материалов, таблица российских аналогов.
4. **Маршрутные карты** — по ЕСТД на каждую деталь и сборочную единицу: маршрут операций, оборудование, оснастка, технологические требования, нормы времени, вид контроля.

### 3. Методика
- Геометрия и дерево сборки извлечены из STEP (OpenCascade/XCAF). Количества — по структуре `NEXT_ASSEMBLY_USAGE_OCCURRENCE` (дерево сборки).
- Массы: `масса = объём тела × плотность материала`; плотности: сталь 7,85, резина 1,15, ПЭ-1000 0,95, полиамид 1,15 г/см³.
- Материалы взяты из свойств модели (iProperties → STEP) и адаптированы:
  | Модель (EN) | Российская марка |
  |---|---|
  | S235 | Ст3сп5, ГОСТ 380-2005 (аналог S235JR) |
  | S355 / S355JR | 09Г2С, ГОСТ 19281-2014 |
  | S355J2G3 | 17Г1С-У, ГОСТ 5520-2014 |
  | Steel, Mild | Ст3кп/Ст3пс, ГОСТ 380-2005 |
  | Rubber | Резина листовая, ГОСТ 7338-90 |
  | PE 1000 | Полиэтилен высокомолекулярный ПЭ-1000 (УПЭ) |
  | Ertalon 6SA | Капролон (ПА-6) |
- Крепёж: DIN/ISO → ГОСТ (см. `docs/Аналоги_ГОСТ.md`).

### 4. Контроль достоверности
- Масса PSH24-070.01 по расчёту **25,93 кг** сходится с чертежом заказчика **25,9 кг** (отклонение 0,1%).
- Заготовка гнутой детали PSH24-070.01 по расчёту **1231×543 мм** близка к официальным **1227×541 мм** (припуск на гибы принят 4%).
- Габариты контуров резки сверены с геометрией модели (совпадение до 0,1 мм).

### 5. Допущения и открытые вопросы
1. Наименования деталей присвоены по конструктивному типу (из STEP имена не выгружались).
2. Для позиций без корректного материала принята Ст3сп5; отмечено в BOM.
3. Следующие позиции требуют подтверждения заказчиком:
   - штифт `DIN 1444 19×92` — прямой ГОСТ-аналог отсутствует, уточнить/изготовить по чертежу;
   - палец `ISO 2341 B 16×100` — замена по согласованию;
   - подшипниковые узлы `UCP-214/218`, `SKF SYJ 70/90 TF`, вставки `YAR 214/218-2F` — отечественные аналоги (ВПЗ/ГПЗ/SN-серия) уточняются по каталогу поставщика;
   - датчик индуктивный M12 — заменяется по параметрам (Sn, схема подключения);
   - устройство `2021_08_31__13-50-03-564` (по паспорту поставщика) — наименование и документацию запросить.
4. Размеры заготовок гнутых деталей окончательно уточняются по оснастке гибки (радиус пуансона, КДР).
5. Нормы времени — расчётные, подлежат уточнению по нормативам производства.
