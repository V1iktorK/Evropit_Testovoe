В соответствии с тестовым заданием по вакансии «Конструктор-конструктор» направляю
выполненные материалы по 3D-модели бункера PSH24-000.00.

Состав комплекта (архив Комплект_КД_PSH24-000.00.zip):

1. 01_Чертежи_2D — рабочие чертежи деталей и сборочных единиц (PDF + DXF):
   • виды по ГОСТ 2.305 (главный, сверху, слева), осевые линии, размерные
     цепочки, цепочки отверстий, изометрический вид;
   • основная надпись и технические требования по ГОСТ 2.104 / 2.312;
   • листы A3/A2, масштабы 1:1 … 1:50 по ГОСТ 2.301.

2. 02_Контуры_резки — контуры раскроя листовых деталей в DXF (масштаб 1:1,
   слой контура, без размеров), пригодны для лазерной/плазменной резки.

3. 03_BOM — спецификация (XLSX + CSV) с массами позиций; для всех материалов
   указаны российские аналоги и стандарты (ГОСТ 380-2005, ГОСТ 535-2005,
   ГОСТ 19903-2015, ГОСТ 11371-78, ГОСТ 6402-70 и т.д.), крепёж приведён
   к отечественным аналогам по ГОСТ.

4. 04_Маршрутные_карты — маршрутные карты на изготовление деталей (128 шт.)
   и сборочных единиц (39 шт.): операции, оборудование, режимы, контроль.

5. docs — пояснительная записка и таблица аналогов материалов.

6. 05_Модель — исходная 3D-модель PSH24-000.00.stp.

Контрольные показатели сходятся с исходной моделью: масса изделия 6259,7 кг,
заготовка детали PSH24-070.01 — 1231×543 мм, масса 25,93 кг.
